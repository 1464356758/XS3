# 《大旱三年，我替县城算活路》｜开书总纲 V1.0（规划稿）
 
> 本文是作者2026-10-28选定T01后的原创规划底稿，**不是已采用正文，也不代表第一章已经发布**。平台沿用上轮17K市场调查作为暂行创作口径；作者说的“7k”是否指17K仍需投稿前确认。规划可在第一章采用前修订，但一旦正文采用，过去事实以冻结章为准。
 
## 01 一句话与读者体验
第三年大旱，北阜县临时赈户三千人，只剩够吃三日的粮。二十三岁的仓房账房许砚被指私吞三百袋官粮，明日就要认罪问斩。要救自己和母亲，他必须在穷人饿死、官府失控、豪强催债之前，找出失粮的真实去向。可他后来发现，粮从来不只是被人偷走，有时是被更有权力的人合法挪走，而得到它的人也同样在挨饿。
 
### 三重持续引擎
1. **当下性命**：人今天怎么吃，粮在哪里，车什么时候到，谁承担担保、押运和治安成本。
2. **权力账本**：谁有权登记、扣粮、调拨、借贷、追责；每赢一场，敌人的权限和收益结构都跟着改变。
3. **不可逆代价**：救县城可能饿村庄，救边军可能断民粮，救万民的制度可能害掉主角的亲友和盟友。
 
爽点来自**用有限的信息和可信行动赢下一步**：让借口变成签字、把假账变成证据、把困局变成众人可以承担的明确选择。禁用现代商业话术式嘴炮、万能外挂、天降巨款和全员无脑配合。
 
## 02 世界与计量硬约束（暂行）
- **架空王朝**：燧朝，景宁十六年，北地连旱第三年。不是某个真实朝代；官名和律例为本书设定，不能引用真实历史律令充当必然规则。
- **初始地点**：宁川州北阜县城。赈户登记三千人，**不是全县总人口**，郊乡更多流民另有缺口。主角在县仓下属登记房做账；仓门、石秤、河渡、县衙有明确通行与管理权限。
- **一袋可发粗粮**：五十斤；本书换算一斤约500克。为便于账算，一切粮额以“斤可食粗粮”记录；湿谷、糠、种粮不能未经折算直接计入。
- **第一章盘库**：账面应存四百六十袋，实存一百六十袋，**缺口三百袋=一万五千斤**。实存八千斤。三千赈户暂按每人每天九两零四钱? **统一为每日每人0.9斤**，日耗2700斤；理论约2.96日，运输与发粮损耗会缩短，不能称精确三天。
- **封存种粮**：另仓七十二袋，五十斤/袋，共三千六百斤；不算入现有救济粮。动它要支付下一季无种可播的代价和权限后果。
- **缺粮去向分层**：开局只确证账实不符三百袋；后续分别核对疑似调拨一百八十袋、疑似旧税抵扣八十袋、疑似报耗四十袋（180+80+40=300）。这些是**规划中的调查假设而不是第一章人物已知事实**，每条要有原件、押运、人证与落地库存，不能看一张纸便自动认定真正去向。
- **时间**：第一卷开篇起点为景宁十六年五月初九清晨，旱灾已持续两年多。第1-10章约覆盖十日内；后续沿粮运与政局可延伸到十四个月，不能每章随意跳季节。
- **空间**：北阜县城至西渡约十四里，干河床可步行，满载粮车实际耗时须高于轻装行人；乡关与州仓另计地形、检查、马匹和车数。不得“半夜跨三县”。
- **制度**：县令可签本县临时赈令，但无权直接挪用邻县官粮；跨县调拨须上级文书、实物押运和到仓验收。证据和公文无法凭主角一句话立刻改变。

| **梁鹤年，51** | 磨坊与粮车联号东家，囤仓与合同持有人 | 有私粮处置权及欠账收据，但非绝对垄断 | 会在法律框架内收割赈灾成本；也确有雇工要养 |
| **韩奉，54** | 城外里正，代表被忽视乡村的赈粮份额 | 能组织村民，不能动用官仓 | 从来不为主角“顾全大局”，每次牺牲都追究明确责任 |

| **郑秉法，53** | 中枢转运制度制定者；后期对立力量 | 能改变核销规则并调动州际资源，不能凭一句话消灭亏空 | 是利益结构和责任外包的代表，不能写成幼稚反派 |
 
**人物信息防串线**：许砚不知道越县真实账和幕后人；谢照禾只知道渡口业务；石景楼知道自己签过什么但不知最终去处；杜延衡知道县衙债务压力但不知所有伪凭证。秘密须有获得路径、证明层次与时点。

## 05 CH001–010 局部桥段路线（第一阶段框架）
- **CH001《八千斤粮》**：清晨开仓，账面四百六十袋实一百六十袋。许砚被押到仓门，廖十二奉命带人问罪。县城赈户三千等待当日配给，许砚提出先保留原账封印、现场复秤以防二次栽赃；第一次意识到封签与出仓副联不一致。**章尾**：一张本应由县仓保管的签收副联，印有外衙改押痕迹。开篇800汉字内先把“失粮与问斩”摆出来，3000汉字内主角采取带成本的行动。
- **CH002《门外三千人》**：官府试图先定罪后发粮，许砚用点验名单争取一个时辰；登记赈户与实际排队人数不匹配，不能把“多排的人”凭空擦掉。**章尾**：城外乡民也挤到仓门，却不在县城赈册。
- **CH003《先分给谁》**：县令批准临时日配，拿出可食粗粮和秤数核账，按人头限额发粮引发争执；赈册公开带来更危险的仇怨。**章尾**：一位老妇指认赈册中两名“已死的领粮人”。
- **CH004《第二把秤》**：由不同计量人和封袋原痕互相印证，发现账上损耗与实物签字不一致；石景楼提出合理辩解，并追问许砚自身经手责任。**章尾**：西渡一艘船并没按账本抵达。
- **CH005《渡口空船》**：谢照禾第一次亮相，不是免费帮忙，而是索取押运风险保价；只核出一段不完整的粮转运链，取得下一份查证路径。**章尾**：旧渡簿上有人把一趟停靠拆成两趟不同货名。
- **CH006《谁先挨饿》**：连日发粮后实际损耗迫使缩减配给，城外乡村指责城里拿走救命口粮；主角公开记下拒绝名单，不允许旁白将其写成“为了大局”。**章尾**：被拒绝的一家人出现不可逆事故。
- **CH007《借粮要押什么》**：梁鹤年愿借私粮，但要求可执行的担保和优先偿还条款；县令不愿签字，许砚提出让后续官债经受公开复核。**章尾**：梁家把偿债凭证递到许母面前。
- **CH008《烧掉的不是账》**：证人退缩，仓房原始回单遭破坏，但不能因烧毁一张纸就“全部真相消失”；许砚用渡口和出入门簿交叉留证。**章尾**：一份回执被篡改的理由指向上级新令。
- **CH009《七十八户》**：韩奉带乡村七十八户名册来谈判，揭示城内赈策造成的真实外溢代价；许砚决定以签字记录“谁被暂不救”。**章尾**：决定当众盖印之人突然反悔。
- **CH010《让谁签字》**：第一阶段兑现。许砚不是“靠口才从天上借粮”，而是在可核实押粮、车马与担保条件下促成县令签署有期限的赈令，赢来后续若干日而非解决旱灾。许砚获得查账授权、留下民怨与待偿债务。**章尾**：州里派来的巡核人宣布赈令未必合规。
 
CH001–005 是下一轮重点细化窗口；CH006–010 为可调整远期路标，不能在未写正文前把每一个反转当作已发生事实。
 
## 06 开篇强制检查点
- **800字内**：可数的粮缺口、具体问罪威胁和城外压力同时出现；不用三页天气和王朝历史开场。
- **3000字内**：主角的行动必须实质改变仓门局面，例如要求当众封存账簿、分离实物和字面数、争取一段受监督的核验时间；不能只“发现自己会算账”。
- **第一章兑现**：证明有账实矛盾并成功拖住定罪程序，**不能直接证明幕后主谋**。明日问斩威胁须由有权限的人实际提出，若程序不允许当日处决，要用“拟报重罪/先拘押待审”等架空律制合理化，不写无缘由的随手砍头。
- **阅读钩子**：末尾留下一条可查线索和具体危险，不靠假神秘和人物突然知道未知消息。
- **前10章复核**：每章带入至少一个不可逆事实变化，冲突不能全是“人群闹事→主角讲话→人群服气”。
 
## 07 长篇耐久性与反循环
1. 每十章检查：新增权力、损失、人物主动选择、物资账本变化、债务余额、失信名单与阶段性承诺是否真实兑现。
2. 任一连续三章如果主角都在“说服官员签单”，下一章必须改用物流行动、现场灾害、法律困局、关系代价或新地域行动，禁止同机制翻新。
3. 每次开仓、借粮、换粮都必须有收、发、耗、押运、路程和接收方账；真正去向未知保留为未知。
4. 人物不因主角聪明就突然弃其自身利益；敌方有正常可执行反扑，盟友可拒绝。
5. 中点以后故事问题由“这几袋粮是谁挪走的”升级为“谁有权决定哪些地方先活下去”；规模扩大，但保留开篇原有的人命责任。
6. 前文冻结后不得再给人物添加“原来他一开始就知道”解释来救剧情。新信息只能从此前未否认的证据产生，必须登记取得路径。
7. 保留别样戏：病房、码头、乡村、官署、家中沉默与人与人之间的亏欠。不是所有章都开会算账。
