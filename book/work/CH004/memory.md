# CH004 章后记忆

首场翌日，礼拜二下午，小满把上一场的带子带进学校，课上老播音员又喊陶素琴，男孩因此把梁月叫错。上午同学们听带子猜位置，老师准她在下午活动课请球员来讲。梁月下早班，起初央姚小芹替她出面。小满只认自己亲眼见过妈妈摔倒，没看清她站哪儿，梁月听见才把鞋袋交给白荻，自己进教室。

讲台前与后排各一扇凳子球门，侧边的书包装作遮眼的车棚。小芹从对端认得梁月拦掉曲苗第一传，看不准哪只脚。小满在看台只瞧见摔倒，亲耳听过妈妈说鞋尖碰了球。她先替妈妈把纸上的红扣留在中路，梁月却亲手搬开代表自己的板凳，承认第一脚挡住后还想抢第二回。小满看见九号进到了那块空处，最后让扮九号的孩子把扣子放在了那里。

比赛原声仍在。第三章车棚下白荻那句“梁姐，那一分算我的”录进去了，小满其后已按停。小满曾拿那句当妈妈可以守在中路的凭据。这一回她把旧带送到原录音以后的空处才录，梁月自己说“我叫梁月”，讲自己挡了哪一下又追了哪一下，同学随后能叫对她的姓。赛后的追问没有在带子上重现。白荻知道女儿当时为何急着按停，在教室里没替梁月抢答。广播报梁月全名这件事仍未发生。

小芹玩笑中讨回昨天没碰到手的击掌。她给孩子们签名，也用炭笔在白荻手上签了姚小芹，反过来请白荻在自己的掌中写个荻。小芹能认这个名字，白荻想要这几个字到什么地步她只见到当下。母女身份仍只有白荻和读者明白。掌中炭迹会蹭掉，白荻回来接球时球上留了一点灰。大姨的底片仍未见冲洗。工人俱乐部没约人，膝伤缘由没有新消息。

虎牙女孩能替同伴找到看台的位置，校门口踢纸团却跑到了球前面。梁月亲口约她礼拜三早七点到东棉旧晒场的红门，自己那日轮休。女孩折回班里，尚无别的孩子来报到。小芹在场听见，随后拐进小街回家。白荻原有的鞋洗后还湿，梁月带来另一双给她穿。两人回到晒场照旧分守门将和中卫，梁月听见球落地仍扭头查白荻有没有出门，慢了第一步，请她从刚才那儿再给一回。下一球还没掷。
