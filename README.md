## 开始写小说

向当前 GPT 对话回复目标创作平台，例如“番茄”或“七猫”。GPT 将核实官方规则与近期榜单，提出5～10个原创选题；由作者确定选题后进行长篇规划，再逐章写作。

- [启动新书.txt](启动新书.txt)：新对话接管与开书规范
- [每日一章指令.txt](每日一章指令.txt)：后续每天只写下一章
- [AGENTS.md](AGENTS.md)：AI写作团队的运行约束
- [写作与叙事检查](docs/写作与叙事检查.md)：写前任务书、读者审读与因果核对
- [连载冻结与发布前检查](docs/连载冻结与发布前检查.md)：**已采用章节不可修改**
- [旧错前向处理](templates/旧错前向处理.json)：已冻结章节发现问题时留痕并在后文处理

## 工程结构

`book/` 保存本书正文、锁定状态、事实记录及任务；`research/` 保存平台和选题证据；`tools/`、`tests/` 保存系统工具与校验；`web/dist/` 包含个人端及代发端的静态页面代码。

系统文件已进入本仓库，但不等于托管网站已经绑定本书。原有工作台需单独添加 `https://github.com/1464356758/XS3`。GitHub Actions 负责代码和状态校验，**不会自行写作或自动投稿**；需要每日定时生成章节时，必须另行真正创建和验证对应定时任务。

## 安全边界

采用章只读；每章回看前章与长期承诺；5章和阶段复核在新章采用之前完成；三轮修订仍不达标时保留问题、不强行定稿。实际发布必须有平台回执或作者明确确认。未确认平台和选题之前不提前生成正式章节。
