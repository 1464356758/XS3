# CH002 章后记忆

第一章试训后的比赛日。白荻已借住体校，替体校食堂备菜管两顿饭。东棉这天招待两队吃早饭。小芹胸前绣西机修厂，深蓝长袖背后白色一号，已是西机头场首发。白荻自己认了想请她来当观众。小芹没换桌，曲苗坐在她旁边。白荻把多的豆花给了东棉中卫梁月，和穿红袜的前锋秀秀打赌洗碗。

大姨在西机车间做铣床活，给几个人缝过号，带来相机和鸳鸯床单照队相。看守厂门是曲苗逗她的一句玩笑。最后两张底片各照一队。白荻自己放掉双人照，在东棉站梁月和年轻替补中间，西机的最后一张由她按快门。曲苗个小，脸有雀斑，纸牌正面写“西机女队”，背面是“小心轻放”。小芹和姐姐都进了镜头，没人见到底片洗出来的样子。

白荻赛时穿姜黄长袖，袖上沾白漆的外衣与长裤留在女澡堂角落的钩上，外层是小芹的劳动布褂。没人翻衣袋。小芹分双棒橘子冰，大的和甜的末口自己吃了。她用脚试出白荻会随鞋尖移动，尚没问出白荻如何判断秀秀变向。白荻盼秀秀攻破小芹的门，这次当面说了。小芹肯分冰，也还惦记那一脚。她知道这个姑娘想给自己拍相，仍不知是女儿。白荻对未来膝伤和本场赛果都无确证。

小满是梁月的女儿，带有棕色人造革套的录音机。她的旧带里听得清秀秀问裤腰，梁月的“哎”得重放才听清。她想带一段真球事回班里。白荻已当面提醒老播音员。领名单时点名的办法被小满放掉了。老人只应进球和换人要报，若看得清梁月的好球，才肯连名带姓叫她。对面半场被车棚和车把挡了一些。试声是窗口边的低声，录音机当时没有录下名字。小满没听到正式播报，手指悬着等开场。

白荻和秀秀已热身。绿手套掌心乳白，梁月捂过，临进场还给了白荻。东棉走刷红漆的大门，西机走从前运煤的窄门。白荻以为小芹朝她举手，其实小芹在接队友抛的球。梁月接住白荻举在半空的手，拍了一下，两人进场。没有开球、进球或伤人。第一章高球前那声“我的”梁月到底听清多少，仍未打开讲。
